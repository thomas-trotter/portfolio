## Overview

The site you are reading right now. Rather than reach for a template, I designed and built it from scratch as a small piece of production software: statically generated pages, a type-checked content pipeline, per-page SEO metadata, and a working contact form — all versioned, linted, and reviewed through pull requests like any other project.

## Content as data

Every project page, blog post, and static page is an MDX file in a `content/` folder, validated by Velite against a schema at build time. Slugs, permalinks, excerpts, and read times are derived in schema transforms rather than written by hand, and the schemas generate TypeScript types the rest of the app consumes — so a typo in frontmatter fails the build instead of silently shipping, and publishing a new project means dropping in one file.

## Design & implementation

The app uses the Next.js App Router with fully static generation: dynamic project and blog routes are pre-rendered from the content collections, and Open Graph metadata is built per page from the same data. The UI is composed from a small set of reusable primitives — cards, tags, sections, form fields — styled with Tailwind CSS design tokens defined in `oklch`, so a colour or spacing decision lives in exactly one place.

## Contact form

The contact form is a React Server Action validated with Zod on the server, with per-field error reporting, a honeypot field to quietly swallow bot submissions, and delivery via the Resend API — no client-side form library and no separate backend.
